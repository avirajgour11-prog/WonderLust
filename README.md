# WonderLust 🏡

WonderLust is a full-stack travel and accommodation platform where users can explore listings, add properties, and share reviews.

### Features
- User authentication and authorization
- Create, edit, and delete listings
- Image uploads using Cloudinary
- Reviews and ratings
- Responsive UI with Bootstrap

### Tech Stack
Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, Cloudinary, Passport.js.

### Architecture
This project follows the **MVC (Model-View-Controller) architecture** to keep the code organized and maintainable.

### Installation

```bash
git clone YOUR_REPOSITORY_URL
cd WonderLust
npm install
```

Create a `.env` file with the required environment variables, then start the application:

```bash
node app.js
```

Open `http://localhost:8080/listings` in your browser.
