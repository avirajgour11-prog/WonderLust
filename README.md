# WonderLust 🏡

WonderLust is a full-stack travel and accommodation platform where users can explore listings, add their own properties, and share reviews.

### Features
- User authentication and authorization
- Create, edit, and delete listings
- Image uploads using Cloudinary
- Reviews and ratings
- Responsive UI with Bootstrap

### Tech Stack
Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, Cloudinary, Passport.js.

### Installation

```bash
git clone YOUR_SSH_REPOSITORY_URL
cd Air_BNB
npm install
```

Create a `.env` file with the required environment variables, then run:

```bash
node app.js
```

Open `http://localhost:8080` in your browser.

### Learning Outcome
Built to practice full-stack development, CRUD operations, authentication, database management, and image uploads.
